## E. BACK HANDLING

No `Activity.onBackPressed()` override exists (`MainActivity` has none). ## G. THE CUT LINE (navigating to a single Compose Activity)

Goal: replace the navigation+Fragment UI layer with one Compose Activity, keeping playback (`AuxioService` / `playback/service/*` and the playback state machinery) and music indexing (`music/*` indexer, `MusicServiceFragment`) untouched.

### (1) Pure UI / navigation — safe to cut
- **Nav graphs:** `res/navigation/outer.xml`, `res/navigation/inner.xml`.
- **Hosts:** `MainActivity.kt` (rebuilt as the Compose Activity), `activity_main.xml`, `MainFragment.kt`, `fragment_main.xml`.
- **Full-screen screen fragments + their layouts** (home, lists, search, detail, settings, about): `HomeFragment`, `AlbumListFragment`, `ArtistListFragment`, `GenreListFragment`, `PlaylistListFragment`, `SongListFragment`, `SearchFragment`, `AlbumDetailFragment`, `ArtistDetailFragment`, `GenreDetailFragment`, `PlaylistDetailFragment`, `AboutFragment`, `RootPreferenceFragment`, `UIPreferenceFragment`, `PersonalizePreferenceFragment`, `MusicPreferenceFragment`, `AudioPreferenceFragment`, and layouts `fragment_home.xml`, `fragment_home_list.xml`, `fragment_search.xml`, `fragment_detail.xml`, `fragment_about.xml`, `fragment_preferences.xml`.
- **Dialogs** (all dialog fragment classes + `dialog_*.xml` layouts + sort/menu decision classes).
- **Base fragment plumbing:** `ui/ViewBindingFragment.kt`, `ui/ViewBindingMaterialDialogFragment.kt`, `ui/ViewBindingBottomSheetDialogFragment.kt`, `ui/DialogAwareNavigationListener.kt`.
- **Layout/behavior helpers used only by the sheet/UI chrome** (if the Compose interpolation replaces them these can go later, but see risk note in (2)): `ui/BottomSheetContentBehavior.kt`, `ui/EatInsetsFrameLayout.kt`, `ui/EdgeFrameLayout.kt`, `ui/CoordinatorAppBarLayout.kt`, `ui/MultiToolbar.kt`, `ui/AuxioToolbar.kt`, `ui/FadingToolbarOffsetListener.kt`, `ui/RippleFixMaterialButton.kt`, `home/ThemedSpeedDialView.kt`.

### (2) Mixed UI ↔ playback/indexing — needs care (the risky set)
- **`PlaybackBarFragment.kt`, `PlaybackPanelFragment.kt`, `playback/queue/QueueFragment.kt`** — These ARE the now-playing UI but bind directly to `PlaybackViewModel`/`DetailViewModel`/`QueueViewModel` and emit playback commands.
