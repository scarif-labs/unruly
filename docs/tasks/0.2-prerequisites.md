## Papercuts

**1. `java` on `PATH` is JDK 26, not 17.**
`/usr/libexec/java_home -V` lists both Temurin 26 and Temurin 17, and **26 is the default**.
Auxio's AGP/Gradle expect 17; a JDK 26 toolchain produces confusing, unrelated-looking
Gradle failures. Fix — pin per-build rather than changing the machine default:

```bash
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
```

Every `./gradlew` invocation in this project must run with that set. Consider adding
`org.gradle.java.home` to `repo/gradle.properties` so it survives outside our shell.

**2. `cmake` and `ninja` are not on `PATH`.**
The buildspec says to install `cmake` and `ninja-build` as system packages. They are
absent from `PATH`, *but* the Android SDK ships its own CMake (`3.22.1`) which bundles
`ninja`, and the Android Gradle Plugin resolves them from the SDK — not from `PATH`.
So no Homebrew install is needed. Left as-is deliberately; if the native build later
complains about a missing generator, install `cmake`/`ninja` via Homebrew as a fallback
rather than assuming the SDK copy is broken.

**3. `sdkmanager` needs licence acceptance and blocks on a prompt.**
Piping `yes` handles it. Without that the install hangs silently in a background job with
no visible output, which reads like a network stall.

**4. `timeout` does not exist on macOS.**
Unrelated to Android, but it cost a round-trip: `timeout 20 cline --version` fails with
`command not found`. Use `gtimeout` (coreutils) or the tool's own `--timeout` flag.
